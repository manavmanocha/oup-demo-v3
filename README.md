
  # Assessment Workflow Platform

  This is a code bundle for Assessment Workflow Platform. The original project is available at https://www.figma.com/design/iWWfc51MzKfQXPjQIMahDc/Assessment-Workflow-Platform.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Testing

  Run `pnpm run test:unit` to execute unit tests with coverage.

  Run `pnpm run test:e2e` to execute Playwright end-to-end tests.

  Run `pnpm run test:ci` to execute the full CI-equivalent test pipeline.
